Panduan Integrasi Google Spreadsheet

Langkah Cepat (Hanya 3 Menit):

  1. Buka Google Spreadsheet Baru (sheets.new) dan beri nama spreadsheet Anda, misalnya Database Profil Guru.
  2. Klik menu Extensions (Ekstensi) → pilih Apps Script.
  3. Hapus kode bawaan di editor Code.gs, lalu salin isi file google-apps-script/Code.gs yang telah tersedia di folder proyek ini.
  4. Di bagian atas editor Apps Script, pilih fungsi setupDatabase lalu klik tombol Run (Jalankan). Berikan izin akses saat diminta Google. Semua tabel/sheet akan otomatis dibuat!
  5. Klik tombol biru Deploy (Terapkan) di pojok kanan atas → New Deployment (Penerapan Baru).
  6. Pilih jenis Web App (Aplikasi Web):
    • Execute as: Me (email Anda)
    • Who has access: Anyone (Siapa saja) ← Wajib agar website bisa membaca data
  7. Salin Web App URL yang dihasilkan (berakhiran /exec), lalu tempelkan pada menu Pengaturan & Google Spreadsheet di dashboard ini.
Catatan Keamanan: Siapa saja hanya dapat membaca data yang dipublikasikan (seperti modul dan profil) atau mengirim formulir pesan. Pengubahan data tetap dilindungi kata sandi administrator.
